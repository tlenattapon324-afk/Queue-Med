สร้างระบบคิวใหม่

🔗 ลิงค์เชื่อมต่อ —
🎫 ออกบัตรคิว (สำหรับผู้รับบริการ)
ส่งให้เครื่อง kiosk / แท็บเล็ต ที่ให้บริการออกบัตรคิว
🖥️ แสดงคิว (สำหรับจอแสดงผล)
ส่งให้จอ TV / monitor ที่แสดงหมายเลขคิวให้ผู้รับบริการ
🖥️ แสดงคิวรวม OPD + IPD (จอเดียวแสดงทั้งผู้ป่วยนอกและผู้ป่วยใน)
จอแยก OPD / IPD แบบเดิมยังใช้ได้ — เลือกได้จากปุ่มบนหัวจอแสดงคิว หรือใส่ &mode=opd / &mode=ipd ท้ายลิงก์
📞 เรียกคิว (สำหรับเจ้าหน้าที่เรียกคิว)
ส่งให้เครื่องเจ้าหน้าที่ / เพิ่มเป็น shortcut บนหน้าจอ
